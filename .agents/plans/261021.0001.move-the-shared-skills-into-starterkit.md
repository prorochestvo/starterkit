## Risks

- **A personal fact reaches starterkit.** Controls: D3, the fail-closed pre-push (template for
  new clones), `--text`, the owner's prose review. Client-side only: `--no-verify`, a hooks-path
  override and API writes bypass it; push protection covers credentials only.
- **A name collision shadows a public skill or agent.** A4 on commit, restore and cut-over.
- **Between Tasks 13 and 14 both copies are listed**: bare names load the frozen personal
  copies; the window is the drain only.
- **A session loses a skill or hook.** Personal copies win until Task 14; Q1, Q8, the drain.
- **Keys** stay out of plugins.

## Trade-offs

- **Location over markers (D2).** No wire script; a skill with personal facts splits in two.
  Reverse: merge the split back.
- **Single copy (D1).** Every public-skill edit is a public PR. Reverse: revert Task 14 and the
  flip, switch the marketplace back.
- **GitHub source everywhere (D5).** Symmetric, rebuild-safe hosts; a public-skill edit is live
  only after PR, merge and `marketplace update` (`main` already requires a PR). Hosts lag `main`
  until updated.
- **Helper links on the marketplace clone**: it can run ahead of the installed plugin between
  `marketplace update` and `plugin update`, harmless for these helpers. Reverse: `<installPath>`.
- **No history import**; B1 names `F`.
