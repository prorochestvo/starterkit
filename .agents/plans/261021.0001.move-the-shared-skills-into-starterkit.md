## Overview

The shared agent tooling lives in the private `ai-cli-config` (`~/.claude` on both owner
hosts). This plan moves it into starterkit as the plugins `core` and `core-hooks`: one copy,
versioned, reviewed and merged like code. What stays in `~/.claude` is private; what is in
starterkit is public. No marker, overlay or export decides it.

Done means: a clean profile installs the plugins and runs a plan, a backlog capture, the
commit hook and a fail-open second opinion; both hosts load every shared skill, helper and hook
from starterkit and none from `~/.claude`; no name exists in both places; no live session lost
a skill or hook; every step had a rollback; every starterkit push passed the gate.

## Risks

- **A personal fact reaches starterkit.** Controls: D3 (no personal facts in public skills),
  the fail-closed pre-push gate on every clone (including new ones via `init.templateDir`),
  `--text` on PR text and squash messages, D6 promotion check. The gate catches tokens, not
  personal prose; the promotion review covers prose.
- **A name collision silently shadows a public skill.** Control: A4 on commit, restore and
  cut-over.
- **The Mac serves an unmerged tree.** Controls: the served checkout on `main` or a working
  branch based on it; other work in worktrees.
- **A session loses a skill or hook mid-cut-over.** Controls: personal copies win until Task 14,
  the Q1 hook snapshot, the drain, a rollback per step.
- **Mac `pipeline` pins jump to the served tree** (Q4); accepted, it also fixes stale pins.
- **Keys** never live in a plugin (Task 9), so a version bump loses none.

## Trade-offs

- **Location over markers (D2).** No wire script, overlays or links; in exchange a skill with
  any personal fact splits in two, and the private part is a separate trigger. Reverse: merge a
  private split back into its public skill and drop the conditional line.
- **Single copy (D1).** Every public-skill edit is a public PR; the hosts' load path changes.
  Reverse: revert Task 14 and the flip, switch the marketplace back, revive `7c68f5f`.
- **Linux by hand (D5).** No cron or served clone; Linux lags `main` until updated.
- **No history import.** The pre-`F` history stays private; B1 names `F`.
