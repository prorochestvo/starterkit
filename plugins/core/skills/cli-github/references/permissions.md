# GitHub operation permissions

- Follow `AGENTS.md` approval requirements. Posting under the user's identity to an external system (including issues, PRs, and review comments) requires prior authorization unless already explicitly authorized for that workflow.
- Operations that need authorization before they run: `gh pr merge`, `gh pr review` (approve, request changes, comment), `gh release create` (and edit/delete), `gh secret set`, `gh variable set`, `gh workflow run`, `gh repo edit`, `gh repo delete`, and any label or milestone change (`gh label`, `gh issue edit --milestone`, `gh api` calls that do the same). Reading is free; these change what other people see or what CI does.
- What counts as authorization: an explicit request in the current conversation that names the action (for example "merge the PR", "create the release"), or a documented workflow the owner invoked for that repository (for example the GitHub issue delivery workflow in `references/issues.md`, which authorizes exactly the steps it lists). A general "go ahead", a plan that mentions the step, or a prior authorization for another repository is not authorization. An owner instruction to merge without handing the step back (for example "merge it yourself") also authorizes merging later pull requests in the same repository for the rest of the current conversation, once their required checks pass.
- Outside the GitHub issue delivery workflow, when a merge is the next step and no authorization covers it, ask the owner once per repository per conversation whether to merge later pull requests yourself, instead of handing over a merge command for each pull request. If the owner declines, hand off each later merge without asking again.
- Never self-merge in the GitHub issue delivery workflow, even when an earlier instruction authorized merging in the same repository.
- Do not treat GitHub API capabilities or token scopes as permission to delete repositories, alter access, or perform destructive actions.
- Confirm the target repository, issue/PR, and intended base before outward-facing changes.
